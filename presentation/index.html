Technical Design Presentation

Project Overview

  • Architecture: Object-Oriented + MVVM
  • Stack: Blazor Server, EF Core, SQLite, QuestPDF
  • Functional scope: new game, resume, history, result export

Design Pattern Analysis

MVVM Pattern

Model: entities such as Player, GameSession, Question, Category.

ViewModel: MainMenuViewModel, GameViewModel, ResultViewModel orchestrate UI state and commands.

View: Razor pages render user interactions and bind to ViewModel properties.

Service Layer Pattern

Business logic is encapsulated in services:

  • GameService: session lifecycle + gameplay actions
  • ScoreService: scoring and statistics
  • PdfExportService: reporting and export

Data Design (EF Core + SQLite)

  • Relational entities with FK navigation:
  • Player 1..* GameSession
  • GameSession 1..* AnsweredQuestion
  • Category 1..* Question
  • Question 1..* AnsweredQuestion

Seed source: clavideDor-blz/data/questions.csv with duplicate protection.

Gameplay Engineering Notes

  • Front Developer: skip question once (persisted as skipped with 0 points).
  • Back Developer: retry flow resets prior answer to avoid duplicate-answer conflicts.
  • Mobile Developer: hint mechanism removes two wrong choices.

Export & Reporting

  • QuestPDF generates professional score report in-memory.
  • Blazor + JS interop triggers browser download.
  • Report includes metrics and analysis notes for player performance.
